# Движение в интерфейсе Nyxo

Правила для всех, кто меняет интерфейс, — и для людей, и для ИИ. Токены
лежат в `:root` в `public/style.css`, раздел «Движение».

## Частота решает всё

- **100+ раз в день** — не анимируется вовсе: переключение чатов на
  компьютере, клавиатурные действия, Esc, закрытие меню сообщения.
- **Десятки раз в день** — едва заметно: новое сообщение, меню, реакция,
  отклик кнопки.
- **Иногда** — обычно: окна, шторки, тосты, смена экрана на телефоне.
- **Редко** — можно красиво: смена темы, «ключи сверены».

## У каждой анимации есть назначение

Одно из трёх: **отклик** (нажатие услышано), **«откуда взялось»**
(сообщение приходит со стороны автора, меню — из точки клика), **смена
состояния** (было — стало). Нет назначения — нет анимации.

## Кривые

| Что | Кривая | Токен |
| --- | --- | --- |
| Появление и уход | ease-out | `--ease-out` |
| Движение по экрану | ease-in-out | `--ease-in-out` |
| Шторки и экраны телефона | «ящик» | `--ease-drawer` |
| Цвет и фон | ease | `--ease` |

**ease-in не использовать никогда**: начало медленное — интерфейс кажется
задумавшимся.

## Длительность

- Нажатие — 100–160 мс (`--dur-press`, 120 мс).
- Меню — 150–250 мс.
- Окна, шторки, экраны — до 300 мс (`--dur-screen`, 250 мс).
- Уход быстрее появления.

## Свойства

- Анимировать только `transform` и `opacity`. Никакого `transition: all`.
- Ничего не выводить из `scale(0)`: начинать с 0.9–0.98 и `opacity: 0`.
- Размытие — только статичное и не больше 8px, никогда не анимировать.
  Исключение — смена значка в кнопке поля ввода (4px → 0 за 200 мс).
- Для частых элементов (тосты, переключатели) — `transition`, а не
  `@keyframes`: переход можно прервать на середине, анимацию — нет.

## Жесты

- Элемент идёт за пальцем без `transition`.
- Решение «довести или вернуть» — по расстоянию или по скорости больше
  0.11 px/мс.
- За краем — сопротивление (обычно × 0.2).
- Касания у самого края экрана (x < 20px) — системные, их не трогать.

## Reduced motion

Меньше и мягче, а не ноль: сдвиги и увеличения заменяются короткими
затуханиями (150 мс), жесты по-прежнему идут за пальцем, но доводка
мгновенная, прокрутка, смена темы и перестановка списка — мгновенно,
бегущие точки стоят.

## Не анимировать

- Переключение чатов на компьютере.
- Закрытие меню сообщения.
- Клавиатурные действия.
- Смену «в сети» / «был(а)».
- Счётчики непрочитанного (только `tabular-nums`).
- Каскад сообщений при открытии чата.

## Проверка

- DevTools → Animations, замедление ×5–10.
- Сеть «Slow 3G»: свой пузырь и профиль появляются сразу.
- Двойной Enter — одно сообщение.
- iPhone (вкладка и значок на экране «Домой») и Android: свайп без
  отставания, клавиатура не закрывается при отправке, двойной тап не
  увеличивает страницу, прокрутка под шапкой не дёргается.
